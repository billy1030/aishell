## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| aishell Client → External Cloud Provider API | Outgoing HTTPS requests with API credentials over TLS |
| aishell Client → Localhost Daemon (Ollama) | Outgoing HTTP requests to http://localhost:11434 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03 | Information Disclosure | Provider Adapters | high | mitigate | Sanitize all error logs and exception messages so API keys from settings or environment are never logged or displayed. |
| T-03-04 | Denial of Service | Ollama Connection | medium | mitigate | Set explicit connect and read timeouts (30.0s) on HTTP client requests to prevent infinite hangs if local daemon becomes unresponsive. |
| T-03-SC | Tampering | Provider Factory Registry | low | mitigate | Whitelist strictly allowed provider identifiers ("ollama", "gemini", "openai", "anthropic") preventing arbitrary class loading. |
</threat_model>

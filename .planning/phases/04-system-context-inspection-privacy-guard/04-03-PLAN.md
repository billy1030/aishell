## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator Screen → Context Display | Sensitive environment variables or system secrets must not be exposed on terminal screen |
| Context Provider Injection → LLM Interface | Injected context must always be sanitized and encapsulated before dispatch |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Information Disclosure | Context Display Panel | low | mitigate | `render_context_table` displays only the allowlist-filtered and regex-redacted `env_vars` mapping from SystemContext, preventing terminal leak of unallowlisted secrets. |
| T-04-06 | Tampering | Prompt Injection in Query Dispatch | medium | mitigate | All context injected into `stream_chat` or `generate_proposal` is processed through `format_system_observation` with boundary tags and escaped closing tags. |
| T-04-SC | Tampering | Package Management | high | mitigate | package-legitimacy gate + blocking human checkpoint for [ASSUMED]/[SUS]. |

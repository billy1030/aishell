## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem / Subprocesses → Inspector | Probing host binaries, git status, and /etc/os-release may encounter corrupted or adversarial data |
| External Git CLI Execution → Shell Process | Git status checks must not hang or execute untrusted subprocess hooks |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Denial of Service | Git Status Probing | medium | mitigate | All git subprocess executions enforce a strict 1-second timeout and capture stderr cleanly, preventing hangs on network filesystems or corrupted repositories. |
| T-04-02 | Tampering | Package Manager Probing | low | mitigate | Probe package managers using shutil.which against trusted system PATH executables without invoking execution hooks. |
| T-04-SC | Tampering | External Dependencies (distro, psutil) | high | mitigate | Dependencies pinned and verified via pyproject.toml specifications. |
</threat_model>

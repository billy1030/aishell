<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User command input → Builtin interceptor / PTY subprocess | Arbitrary shell command strings dispatched to process execution |
| Subprocess → Parent terminal state (termios) | Child process modifying terminal flags (echo, raw mode, cursor) |
| Host signals (SIGINT, SIGWINCH) → Process group | Operating system signals forwarded across process group boundaries |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Denial of Service | Child subprocess process group | high | mitigate | Launch child processes in dedicated process groups (os.setsid), forward SIGINT via os.killpg(), and enforce execution timeouts per D-02. |
| T-01-06 | Tampering | Parent terminal termios state | medium | mitigate | Guarantee termios.tcsetattr restoration in defensive finally blocks upon any child crash or exception to prevent corrupted echo or raw terminal states per Pitfall 2. |
| T-01-07 | Memory Exhaustion | Command output stream buffer | medium | mitigate | Implement circular ring buffer capping retained output to rolling 50KB / 1,000 lines in memory while streaming live to terminal per D-03. |
| T-01-SC | Tampering | pip/uv package dependencies | high | mitigate | Pin explicit version ranges in pyproject.toml and use verified PyPI packages. |
</threat_model>

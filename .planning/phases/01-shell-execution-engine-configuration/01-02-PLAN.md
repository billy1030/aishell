## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Execution Engine → SQLite Database | Execution metadata and untrusted command output text written to history.db |
| Multi-User Host Filesystem → Local SQLite File | Other unprivileged or unauthorized local user accounts attempting to read command audit logs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Information Disclosure | history.db SQLite storage | high | mitigate | Enforce 0700 permissions on $XDG_STATE_HOME/aishell directory and 0600 on history.db so other local users cannot read command logs per D-10. |
| T-01-04 | Denial of Service | SQLite write locking during concurrent sessions | medium | mitigate | Enable PRAGMA journal_mode=WAL; and set PRAGMA busy_timeout=5000; to allow multi-terminal concurrent writes without database locks per D-12. |
| T-01-SC | Tampering | pip/uv package dependencies | high | mitigate | Pin explicit version ranges in pyproject.toml and use verified PyPI packages. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator CLI → CLI Entrypoint | Untrusted shell arguments and command strings cross into Typer argument parser |
| Filesystem Config → Settings Loader | File ~/.config/aishell/config.toml read from disk; must be protected against multi-user snooping |
| Environment Variables → Settings Loader | System environment variables (AISHELL_*, API keys) ingested into Pydantic models |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Information Disclosure | ~/.config/aishell/config.toml | high | mitigate | Restrict file creation permissions to 0600 (owner read/write only) and create parent directory with 0700 per D-15. |
| T-01-02 | Elevation of Privilege | CLI argument injection in config path | medium | mitigate | Validate custom config paths via pathlib.Path.resolve() and restrict path traversal outside allowed directories. |
| T-01-SC | Tampering | pip/uv package dependencies | high | mitigate | Pin explicit version ranges in pyproject.toml and use verified PyPI packages. |
</threat_model>

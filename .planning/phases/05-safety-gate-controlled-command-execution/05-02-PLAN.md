## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Proposal Content → Terminal Display | Malicious or unescaped strings in proposal explanation or purpose could corrupt terminal rendering |
| Interactive TTY → Execution Engine | Non-interactive or piped environments must not auto-execute unconfirmed commands |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03 | Denial of Service | Confirmation Gate TTY Guard | medium | mitigate | prompt_confirmation checks sys.stdin.isatty() and aborts with GateAction.CANCEL if non-interactive, preventing headless processes or scripts from accidentally bypassing the gate. |
| T-05-04 | Tampering | Proposal Display Renderer | low | mitigate | render_proposal uses Rich Markup escaping and structured Syntax objects for bash snippets, preventing terminal escape injection. |
| T-05-SC | Tampering | Rich Terminal Component | high | mitigate | Rich library pinned in pyproject.toml and validated across terminal capabilities. |
</threat_model>

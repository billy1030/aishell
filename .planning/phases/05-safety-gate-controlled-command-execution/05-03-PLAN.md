## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator Edit Input → Shell Runner | Operator may edit command into a high-risk command or inject malicious syntax |
| Confirmation Loop → System State | Aborted or interrupted confirmation loops must not leak state or execute partial commands |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-05 | Elevation of Privilege | Inline Command Buffer Editor | high | mitigate | Any command modified via prompt_edit_command is re-evaluated with classify_risk() and re-prompted through the confirmation gate, preventing unreviewed escalation. |
| T-05-06 | Denial of Service | Execution Gate Loop | medium | mitigate | Cancellation at the confirmation gate (n, Enter, Ctrl+C) immediately unwinds without invoking execute_pipeline() or spawning subprocesses. |
| T-05-SC | Tampering | Prompt Toolkit Dependency | high | mitigate | prompt_toolkit pinned in pyproject.toml and validated across terminal sessions. |
</threat_model>

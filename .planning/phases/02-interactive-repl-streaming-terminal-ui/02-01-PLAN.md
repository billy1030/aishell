## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator CLI / Piped Stdin → CLI Entrypoint | Untrusted shell arguments and arbitrary piped input streams cross into aishell |
| Terminal Output Stream → User Terminal | Rendered ANSI escape codes and markdown formatting emitted to terminal stdout |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Denial of Service | Stdin Pipe Ingestion | high | mitigate | Bound piped stdin ingestion to a strict 512KB maximum limit with warning to prevent memory exhaustion from /dev/urandom or massive logs. |
| T-02-02 | Tampering | Terminal Stream Renderer | medium | mitigate | Rely on Rich Console escaping and detect_terminal_capabilities() to prevent raw unescaped ANSI injection from untrusted input. |
| T-02-SC | Tampering | pip/uv dependencies (prompt-toolkit, pygments) | high | mitigate | Pin explicit version ranges (prompt-toolkit>=3.0.50,<4.0.0, pygments>=2.19.0,<3.0.0) from verified PyPI index. |
</threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Command Output → Diagnostic Engine | Failed command stdout/stderr may contain leaked credentials or prompt injection payloads |
| Diagnostic Engine → AI Provider | Untrusted error text sent across network to model provider |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information Disclosure | Error Output Redaction | high | mitigate | trim_and_redact_output passes error text through PrivacyGuard.redact_credentials, scrubbing API keys, database URIs, private keys, and passwords before transmission per D-01. |
| T-06-02 | Tampering | Untrusted Error Encapsulation | high | mitigate | format_failure_observation encapsulates error data inside &lt;command_failure untrusted="true"&gt; tags and neutralizes tag escape sequences, preventing indirect prompt injection from error logs. |
| T-06-03 | Denial of Service | Output Trimming Limits | medium | mitigate | trim_and_redact_output strictly caps failure context to the last 50 lines and 4KB, preventing token exhaustion and API buffer overflow. |
| T-06-SC | Tampering | Standard Library & Pydantic | high | mitigate | Relies on existing pydantic, standard library re, and internal PrivacyGuard with zero external unverified dependencies. |
</threat_model>
